## 一、全章层面

### 1.1 中心命题

> 废石散体的孔隙结构以两种方式控制灌浆：启动压力梯度的路径积分决定浆液能够到达的范围（可达域），
> 渗透率分布决定可达域内浆液到达的先后；停注规则决定实际充填在何时被截断。设计域、可达域与充填域之间的
> 差集由此分别归因于"结构与注浆压力"（不可达）和"充填过程与停注规则"（可达未填、跑浆）。调控措施
> 相应分为两类：改写可达域（封底与封堵、分段段间凝固、孔位与压力）和改变截断方式（停注判据）。

联系两个层面的物理事实：λ ∝ (1−n)/n、k ∝ n³/(1−n)²，两者随 n 同向有利于流动（"便宜的路也是快的路"），
但 n 由 0.10 增至 0.45 时 λ 只降 7.4 倍、k 升 244 倍——可达性差异温和，速度差异悬殊。

### 1.2 结论的两层归类

| 可达层面（由可达域判定，与停注规则无关） | 过程层面（还取决于渗透率分布与停注规则） |
|---|---|
| 均质场偏下、梯度场翻转（判据 F） | 通道跑浆：通道本可达，跑浆来自配额被快速带走 |
| 胶结壳阻断后续段（分段空转） | 锋面缺额（可达未填） |
| 封底与封堵切断路径 | 绕流空区（时间性） |
| 通道入口代价（钻孔是否穿过通道） | x_f = c(ε)·L_max（停注阈值决定锋面停在何处） |
| 案例工程：无通道不可达；可达性与充填体空隙率无关；交界面临界孔隙率下限（依赖 λ 尺度） | 案例工程：原设计浆量内不跑浆，按终压持续注才跑 |
| 致密包裹体 | 分段代价（阴影区） |

### 1.3 三层评价域与两类调控

- Ω_design ⊃ Ω_reach ⊃ Ω_fill（跑浆时 Ω_fill 落到 Ω_design 之外）。
- 未充填区五类：不可达区、锋面缺额、绕流空区、致密包裹体、段间阴影区。
- 调控两类：改写可达域（在不需要浆去的方向设阻隔；避免在需要浆去的方向形成阻隔）；改变截断方式
  （量压双控、间歇注浆等停注判据）。

### 1.4 创新点（定位）

1. 孔隙率梯度对重力偏置的翻转效应，及其一阶解析判据 F = γp₀/(2ρg) > 1（临界与 τ₀、A 无关），经二维
   可达域与求解器证实。
2. 路径积分可达判据：停滞与任意源压不超过 p₀ 的注浆历程下充填域的严格上包络；据此把结论分为可达层面
   与过程层面，并可由现场现象反推结构（在给定 λ 尺度下反推案例工程交界面孔隙率下限，反推数值随 λ 尺度变化）。
3. 三层评价域的缺陷归因与两类调控的对应；分段灌浆的闭式段长准则 Δ > c(ε)·L_max 与阻隔的双重作用。

"非均质导致优势通道"已由 Talon 等建立（启动附近先沿单一最优通道贯通，随压力升高逐步动员新通道；P0025、P0030、P0049），不作为创新点。

### 1.7 结论对 λ 尺度的依赖（两类划分）

λ = 2τ₀/√(8A)·(1−n)/n，τ₀ 与 A 只以比值进入，二者共同决定 λ 的尺度。τ₀ 取静态屈服应力量级（30 Pa）；若取动态
Bingham 值（w/c 0.5 约 6.5~7.7 Pa），λ 约降为四分之一，低于敏感性区间下端。τ₀ = 7.5 Pa 的可达域补算（2026-10-10）表明，
本章结论分两类：

| 与 λ 尺度无关（结构性结论） | 以本文参数集确定的 λ 尺度为前提（绝对尺度结论） |
|---|---|
| 路径积分可达判据与性质 1~3；三层评价域与五类未充填区 | 停滞距离 L_max 的数值；Π_g 的数值及 Π_g < 1 的适定范围 |
| 翻转判据 F = γp₀/(2ρg)（不含 τ₀；数值检验范围见 4.5.2） | 交界面临界孔隙率下限（本文参数 0.19~0.25；τ₀ = 7.5 Pa 时 < 0.06） |
| 段长准则 Δ > c(ε)·L_max（以 L_max 无量纲化） | 翔振可灌性分区、孔距与段长的具体数值 |
| 案例工程：可达性与充填体孔隙率无关；无交界面不可达 | 各算例的扩散范围与注入量 |

写法：两类划分在 4.3.2 τ₀ 段之后集中说明一次；其余各节只在涉及绝对数值时加“在本文参数下”，不处处设防。

## 二、各节框架

### 4.1 工程问题与废石散体结构概化（含原 4.2 通用部分）

**中心论点**：塌落形成的废石散体须经灌浆胶结方能安全回收残矿，但其结构不可原位测定且强烈非均质，
以均质假设设计在同类工程中已导致跑浆；本章将散体概化为等效孔隙率场控制的变饱和宾汉渗流介质，
以三类代表性结构（塌落分区形成的孔隙率梯度、界面形成的贯通通道、随机非均质）及局部架空骨架研究结构
如何控制扩散与充填。

**4.1.1 工程背景与问题提出（简）**
- 承接第 2、3 章：渐进塌落形成废石散体；下部压密、上部松散为梯度场的物理来源（第 3 章完成后回填）。
- 同类工程引子（匿名，只陈述现象与反差）：原设计按均一空隙率取值，施工中在注浆水平下方远处大量跑浆，
  停工改为先封底。可补一句不依赖模型的算术事实：致密段层内孔隙容量（7.5 × 22 × 0.10 = 16.5 m³/m）
  小于原设计单位走向浆量（28.6 m³/m），注明 10% 为事后推算。
- 文献定位（Talon 等），导出三个问题。
- 措辞：翔振一律"拟""预测"；匿名规则。

**4.1.2 物理概化与研究范围（中）**
- 尺度分离：d₅₀ 约 0.1~0.25 m（翔振采场废石塌落区暴露面现场照片目估：块度以 0.05~0.3 m 为主，个别大块 0.6 m 以上；
  暴露面目估偏大；塌落散体与案例工程倒入的充填体成因不同；取 d₅₀ = 0.15 m；图 4.1-4 现场块度照片，附卷尺，
  拍摄时间与位置待作者补），REV 约 2.5 m，扩散尺度 10~40 m；米级巨型块石不满足，单独显式表示。
- 浆液：主注水泥单液浆（w/c 0.5，宾汉）；双液浆（胶凝约 40 s）仅封底，模型中按预置阻隔处理。
- 工序：分段前进式；停注按注入速率阈值定义（对应现场"终压下注入率小于某值并持续若干时间即结束"）。
- 二维竖直剖面；孔口所在坡面 / 巷道壁为边界。
- 排除项：劈裂注浆、堵塞与滤出、离析泌水、困气、沿走向三维连通。
- 图 4.1-1 工程问题与物理概化：(a) 塌落采空区、散体与注浆钻孔示意；(b) 二维概化模型（孔隙率场、钻孔、
  边界、变饱和锋面、锋前气相）。

**4.1.3 废石散体结构的等效孔隙率场表征（中）**
- 为何用等效孔隙率场：原位孔隙率难以直接测定，已有研究中的采空区孔隙率均由函数模型构造（P0020、P0033）、数值模拟（P0021）或室内及相似材料试验换算外推（P0038、P0039、P0042）得到 [EVIDENCE P0020、P0021、P0033、P0038、P0039、P0042]。
- 两条获取途径：离散元分箱（分箱尺度 ≥ REV；仓库颗粒堆示例 0.184 ± 0.014，视第 3 章是否展开）；
  分区特征 + 碎胀系数构造。
- 代表结构：

**4.3.3 停滞可达判据（重）**
- 导出（严格）：停滞时 q = 0 ⇔ |∇Φ| ≤ λ；沿充填区内路径 Φ_s − Φ(x) ≤ ∫λds；锋面 p ≥ 0 ⇒
  p₀ − ρg(y_x − y_s) ≤ min_Γ ∫_Γ λ ds。重力项与路径无关，最优路径为以 λ 为慢度的最短路，
  最小代价 T(x) 满足程函方程 |∇T| = λ。Π_g < 1 时每步代价为正、路径中间点自动满足（适定）。
- 性质 1：不依赖 k、k_r、μ_p 与流动律（含 Forchheimer），只由 λ 场、p₀、ρ 决定 [SYNTHESIS]。
- 性质 2：充分性只在渐近意义下成立；在 ε = 0.1 的停注规则下，停注时锋面约达 0.87 L_max，
  充填占可达域约 0.93~0.99（现行单段运行，两遍一致）。
- 性质 3（严格，条件如下）：锋面到达 x 时，自源至 x 的流线上 |∇Φ| > λ，故 ∫λds < Φ_s(t) − Φ(x) ≤
  可用压头。对源压始终不超过 p₀ 的任意注浆历程（限流泵送、压力爬升至终压），任一时刻充填域都在以 p₀
  计算的可达域之内；τ₀ 随凝结只增不减时，以初始 λ 计算的可达域是全过程的上包络。条件：理想宾汉、
  各向同性标量迁移率、不可压缩且已充填区不回退、源压 ≤ p₀、气体自由排出。正则化求解器的伪蠕动为数值例外。
  意义：模型时间轴不可与现场比较，但可达判据可直接用于现场工况（4.7 筛选的合法性依据）。
- 措辞：可达域是充填域的上包络（必要条件）；"充填将到达边界"只写渐近成立。

### 4.6 分段灌浆的段间改写规律与阻隔调控

**中心论点**：分段是成孔约束下的必然工序。段间凝固改写后续段的可达域：后续段有效当且仅当新出浆段伸出
前段胶结体（Δ > x_f），在统一停注规则下 x_f = c(ε)·L_max（ε = 0.1 时 c ≈ 0.87），判据化为闭式段长准则；
分段相对理想整孔的代价呈开关特征，由后续段是否有效决定。同一机理下，前序胶结体位于需阻断的方向即为
封堵，位于需充填的方向即为阴影。4 图 2 表。

**对比基准**：一次钻到 17 m 的理想整孔现场难以一次钻至设计孔深（案例工程注浆方案即因此分次钻进），只作对照上界。

  方案明确分段是“为保证注浆钻孔顺利施工”，主工作面分三次钻进（7 m、10 m、17~17.5 m）；工作量统计钻孔约 500 m、扫孔约 493 m

### 4.7 案例工程的机理检验

**中心论点**：某矿山二次注浆工程在三个空隙率迥异的区段都发生远程跑浆。模型表明这是钻孔穿过交界面
（入口代价为零）、通道通透度足够与按终压停注三者共同作用的结果；在本文参数确定的 λ 尺度下，由现场跑浆可反推交界面等效孔隙率下限（反推数值随 λ 尺度变化）；
原设计浆量本身不致跑浆；封底切断全部向下路径且与仰角无关。定位为机理与物理可行性检验，非标定、不复现
浆量与时间。3 图 2 表。

- 合法性：4.3 性质 3（限流泵送、压力爬升均在以终压计的可达域之内）。
- 筛选 144 配置：有交界面（n_c 0.35）三段到跑浆中段代价比 0.76~0.79；三段"代价比—n_c"曲线几乎重合，
  与 1 的交点 n_c ≈ 0.20~0.25（45% 段约 0.20）；一维沿交界面估算约 0.31（二维更低，借道存窿矿石）；
  通道 1 m 与 2 m 宽结果逐位相同。
- 参数区间（C1）：三段阈值 z1 0.227~0.474、z2 0.194~0.474、z3 0.225~0.474；τ₀ 60 与 A × 0.3 两组在
  0.60 时仍不可达；高屈服组二维与一维相差 ≤ 0.005，v0.6 组二维比一维低 0.08~0.12。
- 逆向推断：现场跑浆在模型假设下要求存在代价不超过 p₀ 的贯通路径；若为交界面，其等效空隙率在所有参数组
  中不低于约 0.19，高于 I 段充填体 0.10；高屈服组所需通透度极高，须提示其他路径的可能。
  τ₀ = 7.5 Pa 时该下限降至 0.06 以下、低于 I 段充填体，“交界面须比充填体更通透”不再成立；正文写为本文参数下的
  条件性结论。稳健结论突出“可达性与充填体孔隙率无关”（不依赖 λ 尺度）。
- 有信息量的只有两条："与充填体空隙率无关"（机理即入口代价为零，4.5.3 的现场实例）与"通透度下限"。
  "无通道不可达"因未采矿体不透浆属几何必然，信息量有限。

**4.7.4 上密下疏结构与封底（中偏简）**

### 4.8 翔振采场散体的可灌性预测与灌浆方案（初版，输入待补）

**中心论点（初版）**：以翔振采场散体的等效孔隙率场为输入，在论证所得的注浆压力窗口内，对候选方案进行
"判据预判 → 可达域筛选 → 求解器预测"三级评价，得到采场散体的可灌性分区（可靠充填区、易生缺陷区、
不可达区），并给出推荐方案、参数建议与预期缺陷。全部为预测性结论；可灌性分区作为后续章节布置承载结构
的依据。4~5 图 2 表。

**分工（方式乙，已定）**：第 4 章回答"怎么把浆注进去、哪里能可靠灌实"；第 6、7 章在可靠充填区内布置
承载结构并集成治理方案。4.8 不以人工关键层为前提，依赖单向。

**设计原则**：孔隙率场有不确定性，采用情景分析；推荐方案须在全部情景下满足要求。案例工程双轨使用：
借设计参数（w/c、分段工序、封底做法、量压双控思路），不借观测事实。

**4.8.1 工程条件、压力窗口与评价输入（中）**
- 已知：缓倾层状矿体倾角约 30°，矿体厚度 15 m，埋深约 100 m；上盘炭质板岩（稳定性差），下盘流纹斑岩；
  留矿法仅回采矿房、未处理矿柱；计算剖面为沿倾向的竖直剖面（参照 PFC 采后模型几何）。
- 设计域：采场剖面内废石散体全体，沿倾向取治理段长度。越界 = 浆液流出采场散体（沿上下盘接触面流到治理段
  以外、进入围岩裂隙、进入相邻巷道或采场）；进入残余空区单独讨论（可能本应充填，但属自由面流动，超出模型
  范围，写入局限）。
- 注浆压力窗口（本节论证）：
  - 上限：散体骨架约束应力（散体上方为自由面，竖向应力仅来自自重并受成拱削减，量级约每米 0.02 MPa）与
