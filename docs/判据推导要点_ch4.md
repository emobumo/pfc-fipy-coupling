# 判据推导要点（供 4.3.3、4.3.4 起草）

2026-10-11 整理。只汇总仓库与框架中已有的推导，不含新计算；数字以 `docs/anchors_ch4.csv` 为准（方括号内为锚点号）。
术语按《术语对照表》（2026-10-10）：竖直向上坐标记为 z；路径积分 ∫λds 称累积启动压力，p₀ − ρgΔz 称可用驱动压力；可达域计算输出的合成量 p_req(x) = min_s[∫λds + ρg(z_x − z_s)] 称所需源压（使 x 可达所需的最小源压），判据即 p_req ≤ p₀。框架指《第 4 章论证框架》v1.8。

## 一、路径积分可达判据

**表述**　点 x 可达，当且仅当

    min_Γ ∫_Γ λ ds  ≤  p₀ − ρg(z_x − z_s)

Γ 为自源 s 至 x 的任意路径。重力项只与端点高差有关、与路径无关，故最优路径是以 λ 为慢度的最短路；
最小累积启动压力场 T(x) 满足程函方程 |∇T| = λ。

**锋面不等式**　停滞时 q = 0 ⇔ |∇Φ| ≤ λ（广义 Darcy 截断，Φ = p + ρgz）。设充填域为 Ω_f，锋面上 p = 0（气体自由排出）。
对 Ω_f 内自源 s 至任一锋面点 f 的路径积分，得 Φ_s − Φ_f ≤ ∫λ ds，即

    p₀ − ρg(z_f − z_s)  ≤  ∫_{s→f, Ω_f 内} λ ds

也就是说，在锋面上，可用驱动压力不超过充填域内任一路径的累积启动压力。这只是锋面上的不等式，约束的是充填域内的路径，
不能直接推出判据。判据要从两个方向分别证明。

**必要性**（充填点满足 T(x) ≤ p₀ − ρg(z_x − z_s)）　由流动条件得出，推理同性质 3：浆液到达 x 时，自源至 x 的流线上
有流动，故 |∇Φ| > λ，沿流线积分得 ∫λ ds < Φ_s − Φ(x) ≤ p₀ − ρg(z_x − z_s)（x 处 p ≥ 0）；T(x) 不超过沿该流线的
累积启动压力，所以充填点都满足判据。充填域不回退，停滞后仍然成立。这一方向对源压不超过 p₀ 的任意注浆历程都成立
（条件见性质 3）。

**充分性**（停滞时满足判据的点都已充填）　用反证法。设 x ∉ Ω_f 满足判据，其最优路径 Γ* 自源出发，必在某锋面点 f
首次穿出 Ω_f，且 s→f 段在 Ω_f 内。对该段用锋面不等式：∫_{s→f} λ ds ≥ p₀ − ρg(z_f − z_s)。x 满足判据：
∫_{s→x} λ ds ≤ p₀ − ρg(z_x − z_s)。两式相减：

    ∫_{f→x} λ ds + ρg(z_x − z_f)  ≤  0

即 f 之后的路段上，"累积启动压力 + ρgz"的增量不大于零。但 Π_g < 1 时每一步都有 λ ds > ρg|dz|，该增量恒为正，矛盾。
所以 x ∈ Ω_f。

**成立条件**　必要性对任意注浆历程成立（条件见性质 3）。充分性依赖 Π_g < 1；它也只在停滞意义下成立：定压注浆的锋面
只能渐近逼近停滞状态（性质 2），有限时间停注时充填域只是可达域的一部分。v0.6 参数下 n 0.10~0.30 时 Π_g = 0.03~0.13。
Π_g ≥ 1 时上述反证失效（向下的路段增量可为负）；可达域的最短路仍有定义，因为任一闭合回路上重力项抵消、累积启动压力为
Σλ·ds > 0，不存在负环。

**离散实现**　16 邻域图上的最短路，边权 = 线段上逐面 λ 的积分 + ρgΔz；长边按穿过的每个面计价，不能跨过单层胶结墙。
度量误差只会低估可达域，上界 2.7% [R01]；含重力时为 2.75%/(1 + Π_g sinθ) [R10]。

出处：框架 4.3.3（必要性、充分性的分向证明为 2026-10-11 主线更正）；`src/analysis/fill_diagnostics.py` 模块说明与 `reachable_domain`；
`tests/test_fill_diagnostics.py::test_long_edges_cannot_tunnel_a_one_cell_wall`；`docs/results_log.md`"充填诊断"一节。

## 二、性质 1～3

**性质 1（与流动律无关）**　判据只含 λ 场、p₀、ρ，不含 k、k_r、μ_p，也不依赖流动律的形式。
推导要点：停滞时 v → 0，与速度有关的各项（黏性项、Forchheimer 惯性项）都趋于零，只剩启动压力梯度；
μ_p 只出现在迁移率 k·k_r/μ_p 中，而 λ = 2τ₀/r_eff 只含 τ₀。
成立条件：λ 由 τ₀ 与孔隙结构决定，且不随时间变化。
出处：框架 4.3.3【SYNTHESIS】；`scripts/real_param_selfcheck.py` 末段说明；`scripts/viscosity_aging_bracket.py` 说明。

**性质 2（充分性只在渐近意义下成立）**　判据是充填的必要条件。定压注浆时锋面只能渐近逼近停滞位置：
一维解析解 t(x_f) = (n/(Mλ))[L_max·ln(L_max/(L_max − x_f)) − x_f] 在 x_f → L_max 时发散，有限时间内不能到达。
在 ε = 0.1 的停注判据下，锋面停在 x_f ≈ 0.87 L_max [C03b，0.833~0.906，C03]，单段运行充填占可达 0.926~0.987 [O02]。
出处：`tests/test_verification_ladder.py` 台阶 2b 注释；框架 4.3.3、4.6.2。

**性质 3（任意注浆历程下的上包络）**　对源压始终不超过 p₀ 的任意注浆历程（限流泵送、压力逐步升至终压），
任一时刻的充填域都在以 p₀ 计算的可达域之内。
推导要点：锋面在时刻 t 到达 x 时，自源至 x 的流线上有流动，故沿流线 |∇Φ| > λ，积分得
∫λ ds < Φ_s(t) − Φ(x) ≤ p₀ − ρg(z_x − z_s)。若 τ₀ 随凝结只增不减，λ 只增不减，以初始 λ 计算的可达域就是全过程的上包络。
**成立条件（五项）**：① 理想宾汉流体；② 各向同性标量迁移率；③ 浆液不可压缩，且已充填区不回退；④ 源压 ≤ p₀；
⑤ 气体自由排出。正则化求解器在屈服以下仍有微小迁移率，长时间计算时可使浆液缓慢进入按判据不应到达的区域，这是数值上的例外：块石 C 型旧停注规则的长时间运行中，盖石下 4 个不可达单元（所需源压 1.13 p₀ [K04]）在可达部分于约 2000 s 充满后，到约 3100 s 填入 2 个、约 3970 s 全部填入，其间注入量只增加 0.04 m³/m。现行停注判据在其出现之前停注（1394 s），致密包裹体由求解器保留（`results_log`"块石绕流空区"一节；`outputs/boulder_bypass/`）。
数值佐证：现行停注判据下越界单元 0~5 个 [O01]，其所需源压为 1.0065~1.0463 p₀，均在可达边界一个单元之内。
出处：框架 4.3.3；仓库中无对应推导代码，只有上述数值佐证（`scripts/overshoot_cost.py`、`scripts/overshoot_fill_reach.py`）。

## 三、推论 1～4

**推论 1（均质 + 重力：以源为焦点的椭圆）**　λ 均匀时直线即最优路径，沿方向 θ 的直线满足
λr + ρg·r·sinθ = p₀，即 r(θ) = L_max/(1 + Π_g sinθ)：极坐标下的圆锥曲线，焦点在源，离心率 Π_g（Π_g < 1 时为椭圆），
面积 πL_max²/(1 − Π_g²)^{3/2}；无重力时退化为圆 r = L_max。点源上/下比为 (1 − Π_g)/(1 + Π_g)，
n 0.10 / 0.18 / 0.30 时为 0.936 / 0.877 / 0.773 [R11]。线源沿孔轴法向时 Π_g 乘 cos35°，得 0.898，二维 0.897 [R12]。
数值检验：三个轴向与解析值重合到 0.0% [R08]；扇区最大低估 2.63% / 2.72~2.99% [R09]。
出处：`scripts/conic_check.py` 说明；`tests/test_fill_diagnostics.py::TestConicReach`；`results_log`"4.3 推论验证"V1。

**推论 2（直射线估计与翻转判据）**　见第四节。二维检验：10 组参数下直射线与二维可达域之差为 −0.035~+0.043 [R14]。

**推论 3（阻隔墙）**　厚度为 w、启动压力梯度为 λ_w 的墙，穿过它须付累积启动压力 λ_w·w，
所以当 λ_w·w > 可用驱动压力时墙即封住浆液。胶结体（孔隙率地板 10⁻³）λ ≈ 6×10⁷ Pa/m，为原生体的 428 倍 [P10]，
厘米级厚度即可封住 5 MPa（正文不写具体厚度）。这一条统一解释了后续段失效与封底。
出处：框架 4.3.4；`results_log`"招金断面"一节（λ = 6e7 Pa/m）；`tests/test_fill_diagnostics.py::test_long_edges_cannot_tunnel_a_one_cell_wall`、`test_a_diagonal_wall_seals_its_corners`。

**推论 4（倾斜通道的净启动压力梯度）**　沿倾角 β 的通道向下每走 1 m，累积启动压力增加 λ_c、位置势降低 ρg·sinβ，
净启动压力梯度为 λ_c − ρg·sinβ。一维沿通道的可达长度为 p₀/(λ_c − ρg·sinβ)；λ_c ≤ ρg·sinβ 时向下不受限。
案例工程据此估算交界面临界孔隙率为 0.309（一维）；二维结果比一维低 0.08~0.12（v0.6），参数区间内二维减一维为 −0.115~−0.005 [R25]。
出处：`scripts/zhaojin_c1c2.py` 说明与 C1 一维估算；`results_log`"第 4 章锚点核对的补充"C1 条。

## 四、翻转判据 F = γp₀/(2ρg) 的一阶推导

**设定**　从孔上一点沿孔轴法向打直射线，法向的竖向分量 c = cos35°；
设 λ 在一个扩散尺度内按 λ(z) ≈ λ₀[1 − γ(z − z₀)] 线性变化，γ = |∂lnλ/∂z|（上疏下密时 λ 向上减小）。

**上、下射线**　预算方程分别为

    向上：∫₀^s λ ds′ + ρg·c·s = p₀   ⇒  s(1 + cΠ_g) − γc s²/2 = L_max
    向下：∫₀^s λ ds′ − ρg·c·s = p₀   ⇒  s(1 − cΠ_g) + γc s²/2 = L_max

其中 L_max = p₀/λ₀，Π_g = ρg/λ₀。对小量 cΠ_g、γcL_max 取一阶：
s_up ≈ L_max(1 − cΠ_g + γcL_max/2)，s_down ≈ L_max(1 + cΠ_g − γcL_max/2)，故

    上/下 ≈ 1 + c(γL_max − 2Π_g)

**翻转条件**　γL_max > 2Π_g，即 γp₀/λ₀ > 2ρg/λ₀，λ₀ 消去：F = γp₀/(2ρg) > 1。
所以一阶近似下临界值与 τ₀、A 无关。孔隙率形式：λ ∝ (1 − n)/n，d lnλ/dz = −n′/[n(1 − n)]，
故 n′/[n(1 − n)] > 2ρg/p₀。v0.6 梯度场 F = 2.635 [R15]。
物理图像：一个扩散尺度内结构节省的启动压力（约 ½|∂λ/∂z|L_max²）超过向上爬升所付的重力压头（ρgL_max）。

**近似条件**　① 一阶小量：cΠ_g ≪ 1、γcL_max ≪ 1，幅度偏离 1 的部分正比于 L_max [R18]；
② λ 在一个扩散尺度内按线性（对数线性）变化；③ 直射线、无界介质，不计最短路的侧向绕行与计算域边界；
④ 以孔中点的 λ₀ 为基准。所以 F 写作"一阶近似"，定量以二维为准。

**检验**　F 场族 n(z) = n_mid + n′(z − z_mid)：直射线临界 F* = 1.015~1.021（四组）[R16]；
二维临界 F* 为组 1 0.958、组 4 1.052（1.25 m），组 2 1.003、组 3 1.052（0.625 m）[R17]，即 F* ≈ 0.96~1.05。
出处：`scripts/flip_criterion.py` 说明与 `group_v3`；`results_log`"4.3 推论验证"V2、V3；框架 4.3.4。
