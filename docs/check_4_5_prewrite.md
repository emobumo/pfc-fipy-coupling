## 一、必须解决的两项

### 1. K02（4.5.4）

块石局部模型的口袋是盖石下、两支撑石之间的 2 × 2 m 区域，x −1～1 m、y 6～8 m，共 16 个 0.5 m 单元，全部为孔隙单元（`cases/boulder_bypass.py` POCKET）。口袋各类比例在 `pocket_record`（`cases/boulder_bypass.py:141-156`）中按单元面积计算；均匀网格下面积占比等于单元数占比。

**(a) 封闭比例的定义**

- **`pocket_bypass`**：
  - 分子：口袋内判为绕流空区（BYPASS_VOID）的单元面积。
  - 分母：口袋总面积 4 m²。
  - 不是按注入量，也不是按未充填孔隙总面积。
- **其余三项同分母**：`pocket_filled`（已充填，含越界）、`pocket_enclosed_unreachable`（致密包裹体）、`pocket_overshoot`。
- **全域口径**：全域的绕流空区面积另记为 `bypass_area`。首次封闭时 A、B 为 3.5 m²、C 为 3.0 m²，即全部在口袋内。
- **注入量占比（框架的“75%”）**：分子是本段累计注入量 V_in，分母是可达孔隙体积 cap = Σ n·A（初始可达域内单元）。A / B / C 的 cap 为 44.640 / 48.285 / 47.655 m³/m。

**(b) “首次封闭”的定义与时刻**

- **分类频率**：每 25 步分类一次（`CLASSIFY_EVERY = 25`，循环步号 step % 25 == 0，记录中 step 为步号 + 1）。
- **判定**：首次封闭是第一个 `pocket_bypass > 0` 的分类帧。它就是首次出现封闭分量的那一帧，因为全域绕流空区只在口袋内。
- **分类规则**：
  - `classify_unfilled(s_c = 0.5, solid_phi = 0.01)`；
  - 按共面 4 邻接求未充填孔隙单元的连通分量；
  - 接触计算域外边界的分量不封闭；
  - 孔隙率 ≤ 0.01 的块石单元不计为孔隙。
- **精度**：只能定到一个分类间隔。

- **容易混写的巧合**：A 首次封闭时的注入量占比（75%）恰好等于 C 首次封闭时的口袋绕流占比（75%）。正文建议两个量都带上名称。

**(f) 候选措辞**

1. 依据 0.625 m 可达域（NM02）：
   > 重力与孔隙率梯度的效应不能简单相乘：单项之积比组合值高约 0.04（可达域，0.625 m 网格，两种读法一致；1.25 m 上可达域与求解器同号同量级）。
2. 依据 1.25 m 误差传递，最保守：
   > 两效应近似相乘，单项之积比组合值高约 0.04，与三个比值读数误差的合成量相当。
3. 机理导向，依据 NM02 与 NM03：
   > 单项之积略高于组合值（差约 0.04），直射线估计同号（约 0.02），反映 λ 沿高度的非线性分布。

### 6. 评价指标的计算式

- **设计域**：均质基准（2.5 m）停注时 S ≥ 0.5 的单元，共 175 个。出浆单元 S ≡ 1，故等于“S ≥ 0.5 ∪ 出浆段”，含全部 10 个出浆单元（`C.run` 的 `filled_mask`，`outputs/rerun_rate/A/target_mask.npy`）。
- **设计域充填率**：
  - 计算式：设计域不计出浆单元的 165 个中，S ≥ 0.5 的单元数 / 165。按单元计数；均匀网格下等于面积占比；**不是**孔隙体积加权，越界单元计入已充填。例：孔口通道 108/165 = 0.6545。
  - 另一个容易混用的量：results.json 的 `target_filled_fraction` 是 175 单元口径，且只计 FILLED 类、不计越界，孔口通道为 0.6743。ε = 0.05 表中的 67.4% 即此口径，与 65.5% 是同一算例。
- **设计域外浆量**：Σ n·clip(S, 0, 1)·A，对设计域外、非出浆单元求和。按孔隙体积加权，含 S < 0.5 的部分饱和单元（`fig_4_5_5.py`）。
- **设计域外浆量占比**：
  - 分子：上一条的设计域外浆量。
  - 分母：计算域内浆量 Σ n·clip(S)·A，对全部非出浆单元求和。孔口通道 40.3148 / 185.8687 = 0.2169。若以 V_in 为分母则为 0.2167，两者都写 21.7%。
- **注入量与计算域内浆量之差**：
  - 数值：均质基准 0.2150、孔口通道 0.2014 m³/m。
  - 构成：压缩储存 Σ c(p − p_init)V 与截断量（负值），两项在这些算例中未分别存盘。量级参照 2.5 m 梯度完整守恒统计：0.279 与 −0.017。

- **与 4.4.1 的一致性**：
  - Ω_fill = S ≥ 0.5 ∪ 出浆段：一致。
  - 拓扑判别（4 邻接、接触外边界不封闭）：用的是同一 `classify_unfilled`，一致。
  - 现行值 65.5% / 21.7%、78.2 / 76.4 / 77.0% 等按上述口径计算。
