## 2. 按碎胀比修正散体范围（图 1）

**原位面积**：A₀ = PFC 散体颗粒实体面积 ÷ (1 − 0.1416) = 1562.52 / 0.8584 = **1820.27 m²**。PFC 散体区 1922.56 m² 相当于 1.056 A₀。

**修正方法**：
- y_top(x) 取每个 0.25 m 宽单元列中 PFC 散体的最高点。
- 新散体 = 腔体内 y ≤ y_top(x) + Δ 的单元。二分 Δ，取面积首次不小于 K·A₀ 的值。
- 腔体内其余单元为残余空区。
- PFC 散体的水平范围（X −28.38～67.62 m）覆盖了腔体的全部单元列，**没有需要外推的列**，范围内也没有缺少散体的列。

## 对 4.8 的直接信息

1. **两个情景下 F 的符号是否一致：一致，但情景二的整体 F 接近 0**。
   - 整体 F 都为负：p₀ 1 / 2 MPa 时，情景一 −0.179 / −0.358，情景二 −0.020 / −0.039。
   - 局部符号逐单元一致率 0.86：下盘松散底层两个情景都是 100% F < 0；内部约 70% F < 0；上盘侧约 70% F > 0。
   - 上盘侧 F > 0 来自映射给顶部 3～5 m 赋的松带（3.1 第 1 条），映射方式改变时这部分的符号可能改变。底层的 F < 0 不受影响。
2. **下盘松散底层的通道入口所需源压是否为 0：是**。
   - 四个孔在两个情景下都为 0。
   - 孔 1～3 的孔口管末端已进入散体 0.26～0.71 m；孔 4 的孔口管末端仍在岩体内（距散体 0.03 m），出浆段一开始就进入底层。
3. **沿下盘松散底层能否到达散体区下端：只有最低的孔 1 能到，且需 p₀ = 2 MPa**。
   - 孔 1 需 1.175 MPa（情景一）/ 1.519 MPa（情景二）。1 MPa 不够，2 MPa 可达（比值 0.588 / 0.759）。
   - 孔 2～4 需 4.5～11.2 MPa，在 2 MPa 下都到不了。
   - 但四孔并集在 2 MPa 时覆盖了底层的 95.0%（情景一）/ 98.5%（情景二）。
4. **p₀ = 1、2 MPa 时上盘侧区域能否到达：每个孔都能到达一部分，但覆盖不全**。
   - 单孔：1 MPa 时为上盘侧区域的 3～9%，2 MPa 时为 5～22%。
   - 四孔并集：1 MPa 时上盘侧仍有约 72% 未覆盖，2 MPa 时约 39～40% 未覆盖。
   - 未覆盖部分集中在散体下端的上盘侧角部（X < −5 m）和相邻孔之间的中厚部到上盘侧（第 4.2 节第 1、2 类）。
5. **散体顶面位置（K）对上盘侧可达性的影响有多大：很小**。
   - 孔 2（情景一）的上盘侧可达比例在 K = 1.15～1.40 之间为 0.094～0.101（1 MPa）和 0.216～0.223（2 MPa），变化 ≤ 0.007。
   - 空区接触长度为 12.3～14.5 m（1 MPa）和 31.5～34.5 m（2 MPa）。
   - K 改变的主要是残余空区的大小：805.62 → 354.19 m²。
