# 第 4 章术语对照表

2026-10-09 定稿。正文、图题、坐标轴和图例一律使用本表的正式术语。“代价”一词在正文中不再出现：4.3、4.5、4.7 中的路径积分 ∫λds（量纲 Pa）称为累积启动压力；4.6.3 中分段相对理想整孔的充填损失（单位百分点）称为分段覆盖损失。

孔隙率符号全章统一为 n，原 φ、φ_c、φ_top 相应改为 n、n_c、n_top。

## 表 1　需替换的工作用语

| 工作用语 | 含义 | 正式表述 |
| --- | --- | --- |
| 代价、路径代价 | 沿路径的启动压力梯度积分 ∫λds | 累积启动压力 |
| 最小代价、代价场 T(x) | 到达各点的最小累积启动压力 | 最小累积启动压力、最小累积启动压力场 T(x) |
| 最优路径 | 累积启动压力最小的路径 | 最优路径（首次出现时说明） |
| 入口代价 | 通道入口处的最小累积启动压力 | 通道入口累积启动压力 |
| 代价比 | 两条路径累积启动压力之比 | 累积启动压力比 |
| 净代价 | 沿倾斜通道向下每米 λ_c − ρg·sinβ | 净启动压力梯度 |
| 分段代价、代价为开关 | 分段相对理想整孔的充填损失及其两态分布 | 分段覆盖损失；分段覆盖损失呈两态特征 |
| 便宜的路也是快的路、又便宜又快 | λ 小处 k 也大 | 启动压力梯度低的区域渗透率也高；优势通道同时具有低启动压力和高渗透率 |
| 截流浆液 | 优势通道优先吸走浆液 | 优先分流浆液 |
| 锋面缺额 | 可达但因停注未充填的锋面外侧区域 | 锋面截断区 |
| 设计缺陷、充填缺陷、纯充填缺陷 | 设计域内不可达部分；可达而未充填部分 | 可达层面缺陷；过程层面缺陷 |
| 目标区、目标区充填率 | 设计域中不计钻孔单元的部分 | 设计域、设计域充填率（在 4.5.1 说明不计钻孔单元） |
| 跑浆量、跑浆占比（作为图表指标时） | 停注时设计域以外的浆量 | 设计域外浆量、设计域外浆量占比；“跑浆”只用于描述现象 |
| 分段空转、胶结壳阻断 | 后续段被前序胶结体阻断而不进浆 | 后续段失效 |
| 胶结壳 / 胶结体 | 前序段凝固后的浆液固结体 | 前序段胶结体 |
| 配额、配额耗时 | 结构场算例统一的停止体积及其注入时间 | 给定注浆量；给定注浆量的注入时间 |
| 交界面通透度下限 | 由跑浆反推的交界面孔隙率下限（n_c ≈ 0.20～0.25） | 交界面临界孔隙率下限 |
| 空隙率（案例工程） | 工程方推算的充填体空隙率 | 孔隙率；4.7.1 首次出现时说明工程方所称空隙率即本文孔隙率 |
| 十字对照 | 通道位置与孔隙率的交叉比较 | 位置与孔隙率的交叉对比 |
| 上/下比 | 向上与向下扩散距离之比 | 上下扩散距离比（首次定义符号） |
| 偏下、偏上 | 扩散的方向偏置 | 向下偏置、向上偏置 |
| 可用压头 | 源压减去位置势 | 可用驱动压力 |
| 压力爬升 | 注浆压力逐步升高至终压 | 注浆压力逐步升至终压 |
| 贴墙 | 贯通带贴近计算边界 | 贴近计算域边界 |
| 伪蠕动 | 正则化引起的缓慢虚假流动 | 正则化引起的数值蠕变 |
| 现梯度场 | 本文所用的梯度场算例 | 梯度场算例 |

## 表 3　注浆工程通用用语

跑浆、不起压、扫孔、封底、封堵、量压双控、间歇注浆，可直接使用。跑浆在正文首次出现时说明含义（浆液沿非设计方向流失至设计域外）。引用现场记录时可加引号保留原话。
