## 一、段间更新与分段实现

### 1. 段间凝固更新

**代码**（`src/models/slurry_transport/stage_update.py:166-185`）：

```python
n_k = np.clip(_to_array(state["porosity"]), 0.0, 1.0)
s_k = np.clip(_to_array(state["saturation"]), 0.0, 1.0)
n_raw = n_k * (1.0 - s_k)
n_next = np.maximum(n_raw, floor)
floor_clipped_step = float(np.sum((n_next - n_raw) * vols))
...
k_next = porosity_to_permeability(n_next, params)
mobility_next = k_next / mu_p
state["porosity"].setValue(n_next); state["permeability"].setValue(k_next)
```

- **floor**：`stage_porosity_floor` = 1×10⁻³（`variables.py:94` 默认值；各算例未改）。被 floor 拒绝扣除的体积计入 `floor_clipped_volume_total`，守恒恒等式因此严格成立。
- **S_k**：取第 k 段停注时的连续饱和度（截入 [0, 1]），不做阈值处理。
- **作用范围**：全部单元，包括部分饱和单元和出浆单元。
  - 出浆单元在段内 S ≡ 1，凝固后 n 降到 floor。
  - S = 0 的单元 n 不变。
- **k 与 λ 的重算**：
  - k 由新 n 按式（4-7）重算（`porosity_to_permeability`，calibrated_power：A n³/(1 − n)²）。
  - λ 不单独存储，求解器每步由面 k、面 n 按 λ_f = 2τ₀/√(8k_f/n_f) 重建（与式（4-8）同构造）。
  - τ₀、A 不变。
- **段间重置**（`stage_update.py:209-222`）：
  - 下一段出浆单元 S = 1，其余 S = 0；
  - p 在出浆单元为 p₀，其余为 0；
  - 段内守恒统计的计数器清零（注入量、截断量、压缩储存）；
  - `last_div_q` 置空。
- **基准 5 的 λ 比 428.14**：对应 n = 1×10⁻³（floor）与 n = 0.30。λ(0.001)/λ(0.30) = (0.999/0.001)/(0.70/0.30) = 999/2.3333 = 428.14。

## 三、4.6.3：覆盖损失

### 10. 覆盖率与覆盖损失的计算式

- **分段终态的充填判定**：在 `run_sequence` 末（`inclined_hole_staged.py:250-260`）计算累计占据率 occupied = (n₀ − n_final)/n₀，以 occupied ≥ 0.5 为已充填。
  - 本次逐单元核对：C 层 25 个运行与 P1 的 2 个分段运行（共 27 个，其中 16 个分段、11 个整孔）中，“occupied ≥ 0.5 ∪ 出浆单元”与“各段 S ≥ 0.5 新充填单元之并 ∪ 出浆单元”全部逐单元相同。
- **覆盖率**：`over_reach_filled` = `classify_unfilled(...)["over_reachable"]["filled_fraction"]`（`fill_diagnostics.py:466-503`）。
  - **分子**：Ω_reach^w 内类别为 FILLED 的单元面积，即 |Ω_fill ∩ Ω_reach^w|。越界单元（已充填但在 Ω_reach^w 外）不在 Ω_reach^w 内，不进分子也不进分母。
  - **分母**：|Ω_reach^w|，含出浆单元；出浆单元被计为已充填（`filled[src] = True`）。
  - **计数方式**：按单元面积，均匀网格下即单元计数。不是孔隙体积加权。
- **覆盖损失** = 理想整孔覆盖率 − 分段覆盖率，单位为百分点（`fig_4_6_3.py:points`）。两者的 Ω_reach^w 是同一个，单元数相同。
