## 三、论证主线摘要（详见框架文件）

### 3.1 中心命题

> 废石散体的孔隙结构以两种方式控制灌浆：启动压力梯度的路径积分决定浆液能够到达的范围（可达域），
> 渗透率分布决定可达域内浆液到达的先后；停注规则决定实际充填在何时被截断。设计域、可达域与充填域之间的
> 差集由此分别归因于"结构与注浆压力"（不可达）和"充填过程与停注规则"（可达未填、跑浆）。调控措施相应
> 分为改写可达域（封底与封堵、分段段间凝固、孔位与压力）和改变截断方式（停注判据）两类。

联系两层的事实：λ 与 k 随 n 同向有利于流动，但 n 0.10 → 0.45 时 λ 降 7.4 倍、k 升 244 倍。

| 可达层面（与停注规则无关） | 过程层面（取决于渗透率分布与停注规则） |
|---|---|
| 均质偏下、梯度翻转；前序段胶结体使后续段失效；封底与封堵；通道入口所需源压；案例工程无通道不可达、与空隙率无关、临界孔隙率下限；致密包裹体 | 通道跑浆；锋面截断区；绕流空区；x_f = c(ε)·L_max；案例工程原设计浆量内不跑、按终压才跑；分段覆盖损失 |

## 四、控制方程、判据与闭式关系

    n·∂S/∂t + ∇·q = 0
    q = −(k·k_r(S)/μ_p)·max(0, 1 − λ/|∇Φ|)·∇Φ ,   Φ = p + ρgz
    λ = 2τ₀/r_eff ,  r_eff = √(8k/n) ,  k_r(S) = S³ ,  k = A·n³/(1−n)²

**闭式**（√(8A) = 10⁻³ m）：λ(n) = 6.00×10⁴·(1−n)/n Pa/m；L_max(n) = 83.33·n/(1−n)·(p₀/5 MPa) m。
**无量纲**：Bn = λL/p₀；Π_g = ρg/λ（n 0.10~0.30 时为 0.03~0.13）。

**可达判据**：x 可达 ⇔ min_Γ ∫_Γ λ ds ≤ p₀ − ρg(z_x − z_s)；最小累积启动压力 T(x) 满足程函方程 |∇T| = λ。
- 停滞状态严格成立；性质 3：源压始终 ≤ p₀ 的任意注浆历程，任一时刻充填域在可达域内（条件：理想宾汉、各向
  同性、不可压缩不回退、气体自由排出；τ₀ 只增不减时按初始 λ 计）。

**推论**：
- 均质 + 重力：r(θ) = L_max/(1 + Π_g sinθ)（椭圆，焦点在源，离心率 Π_g）。
- 翻转判据：F = γp₀/(2ρg) > 1，γ = −∂lnλ/∂z（有符号）；孔隙率形式 n′/[n(1−n)] > 2ρg/p₀；R_ud ≈ 1 + cosα(γL_max − 2Π_g)。
- 阻隔：λ_w·w > 可用驱动压力；通道净启动压力梯度 λ_c − ρg·sinβ。

**停注判据**：Q̄(t) = [V_in(t) − V_in(t − 0.1t)]/(0.1t)；Q̄/Q_ref < 0.1；Q_ref = k(n_ref)·p₀/μ_p。
**分段准则**：后续段有效 ⇔ Δ > x_f；x_f = c(ε)·L_max，c(0.1) ≈ 0.87（19 个独立段过原点拟合）；ε = 0.05 只有 n 0.18 一个算例，x_f/L_max 由 0.87 增至 0.90，不作为 c(0.05)。

**段间凝固**（式（4-30））：n_{k+1} = max[n_k(1 − S_k), 10⁻³]，S_k 取停注时的连续饱和度，k 与 λ 随之重算，S 重置；第 k 段出浆段取孔口至 d_k 的全孔段，已胶结孔段孔壁不再进浆；段内 n、k 冻结。分段准则式号为（4-31）~（4-33）。

## 六、基本假设与局限

**基本假设**：骨架刚性；结构场一次给定（段间凝固例外）；变饱和 S ∈ [0,1]；宾汉、参数常数（时变两端界定）；
无堵塞；不用 R–vG（P0074）；气体自由排出；等温不可压；定压源（性质 3 保证可达判据不依赖此假设）。

**局限**（初稿按"评阅人不写即视为错误"筛选）：
- 块石下困气不能模拟。
- 劈裂注浆、堵塞与滤出、离析泌水、地表隆起不在模型范围；翔振注浆压力须在劈裂与抬动上限以下（4.8 压力窗口）。
- 二维：沿走向连通看不到；剖面线源代表沿走向一排孔（帷幕假设，要求孔距 ≲ 2x_f）。
- 定压源不能复现"压力起不来"的过程，时间轴不可与现场比较。
- 边界封闭：贯通带算例必然贴墙；封底算例只证明"浆不往下走"。
- 残余空区中的自由面流动超出多孔介质模型（翔振）。
- 正则化引起的数值蠕变：在 4.5～4.7 的算例中停注判据在其之前停注；低压下（翔振 1、2 MPa）蠕变先于停注判据出现，以可达域充填比例 0.95 的状态为分析状态；仍以可达域判定永久性。

- 空间均匀 μ(t) 严格等价于时间变换；慢端 / 快端界定，真实状态预期居间；不改 L_max。
- 新判据下（1.25 m）：梯度 1.17~1.22 各时刻向上偏置，均质 0.91~0.97（慢端 0.97 在读数误差内）；快端与 A 层逐位相同。
